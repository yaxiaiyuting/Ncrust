# H1 证伪实验：名单内的**用户自装第三方**（抖音）是否被拒？
# 采集时间: 2026-09-25T13:23:06+08:00   设备: WVQ6R22124000968 (WGR-W09 / HarmonyOS 4.2 / API 31)
# 目的: whitelist-criterion.md §8.2 的 H1 原本只是「高置信推断」——
#       「名单是唯一准入判据」缺一步穷尽证明。本实验把它补上。

## 为什么选抖音
  包名 com.ss.android.ugc.aweme 在 third_app_filter.xml 的 mediasession 名单里
  （条目 version="25.3.0" 与通配 version="0" 各一条），
  且它是**用户自己安装的第三方应用**，不是华为预置、不是系统应用。
  设备上装的版本是 40.6.0 —— 同时验证了「version 0 通配」这一条。

## 结论
  名单内的用户自装第三方（抖音）=> 0 次拒绝；名单外的 Ncrust => 反复被拒。
  ⇒ H1（唯一准入判据就是包名在不在名单里）由「高置信推断」升级为**已证**。
  ⇒ 同时排除「只认华为预置应用」「只认华为签名」两种解释：抖音既不是预置、也不是华为签名。
