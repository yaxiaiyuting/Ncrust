############ 设置迁移（v2.5.0 老用户 → v2.5.1）############
  升级前 S6 的 ncrust_settings.xml（见 s6-settings-before-upgrade.xml）：

  升级后（键仍然不存在）：

  证据截图：screenshots/v251-s6-migration-default-on.png

############ 开关：可切换 / 立即生效 / 持久化 ############
  ① UI 点一下「页面切换动效」 → 盘上出现 page_transition_enabled="false"（写盘路径通）
  ② 再点一下                  → page_transition_enabled="true"
  ③ **不重启**切换 → 行为立刻改变：
       - 切换前后 pid 恒为 23342（同一个进程）⇒「立即生效」不是靠重启实现的
       - 录屏逐帧分析（screenrecord 30fps + 帧间差）：
           转场 ON ：帧差为 4.3 / 12.8 / 12.4 / 6.9 / 3.9 / 1.9 … 连续 7~8 帧渐变
           转场 OFF：**单帧跳变 41.5**（一帧内从列表整页变成详情页）后归于平静
         证据帧：screenshots/v251-s6-transition-on-midframe.png（详情页返回箭头与列表同帧半透明叠加）
  ④ am force-stop + 重启 → 盘上仍为 "true"，UI 仍为 checked=true ⇒ 持久化成立
  证据截图：screenshots/v251-s6-setting-on-after-restart.png

############ S6 歌曲菜单第 10 条（v2.5.0 抓到的回归）############
  转场开关与菜单无关；本轮在 **release 包**上复核：
    打开菜单（10 条操作）：加入歌单 / 加入本地歌单 / 加入库 / 插播 / 最后播放 /
      移除收藏 / 添加到下一首播放 / 转到歌手 / 转到专辑 / 单曲信息
    滚动前可见到「转到歌手」[224,2443][224,2518]，「转到专辑」「单曲信息」在屏幕外
    在菜单上滑一次后：加入库[224,843] … 转到专辑[224,2187] 单曲信息[224,2411][468,2486]
    ⇒ **10 条全部可达**，与 v2.5.0 在 debug 上的实测坐标一致
  结论：该缺陷**不是 release-only**（v2.5.0 是在 debug 包上抓到的），
        本版在 release 上复核通过。证据截图：screenshots/v251-s6-menu-scrolled.png

############ 动效量化（dumpsys gfxinfo framestats · 只有 release 包）############
  见 EVIDENCE.md §4 与原始文件 s6c-*-framestats.txt / s6c-pop-*.txt。
  摘要（S6 / Android 7.0，90 分位帧时间）：
    列表滚动        19 ms
    播放页展开/收起  27 ms
    页面切换聚合 ON  36 ms   vs OFF 32 ms
    仅「返回」这一步 ON 34 ms（120 帧/6 轮） vs OFF 19 ms（30 帧/6 轮）
  调参实验：把转场改成「纯不透明位移（去掉 alpha 混合）」实测 **更差**
    （90 分位中位 34ms → 40ms），已回退，本版不动效参数未改。
