设备与面板几何与修复前**完全相同**（同一台手机、同一首歌单、同一个大屏模式）：
`0715f763f54c023a` · 横屏 `app 2560 x 1440, rotation 1` ·

口径与修复前一致：`frac_itemtop = (节点文本 top − 40px item 内边距 − 面板 top) / 面板高`。

## 未能在真机上完成的两项（如实记录）

1. **「触碰重置 5s 计时」的端到端时序**：计划是「滑动 → 3.5s 时触碰面板顶部留白 →
   在 5.9s（若不重置应已回正）与 9.3s（若按触碰后 5s 重算应已回正）各测一次」。
   脚本执行到测量阶段时**手机从 USB 掉线**（`adb devices` 不再列出该 serial；
   `lsusb` 仍能看到三星设备 `04e8:6860`，重启 adb server 与 `adb reconnect` 均未恢复），
   两次 dump 都失败。**这一项没有真机数据。**
   它的逻辑由 `LyricsAutoCenterTest` 的单测覆盖
   （`按下再抬起会产生两个新世代（计时从松手那一刻重新开始）` 等 4 条）。
2. **「拖拽进行中不打断」**：需要在一根手指按住不放的同时测量，adb 的
   `input swipe` 是一次性注入、无法在按下状态暂停测量。同样只有单测覆盖
   （`LyricsAutoCenter.shouldRecenter(pointerDown = true, …) == false`）。

这两项在 `CHANGELOG-v2.3.0.md` 的「未验证缺口」里再次列出。
