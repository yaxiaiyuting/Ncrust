**上滑** `0.3599→0.1649→0.1649(+10.6s)`。

## 3. 根因（代码路径，只读审计）

`NcrustLyricsPanel.kt` 的 5s 超时分支只做两件不滚动的事
（`userScrolling = false; lastAutoScrolledIndex = -1`），
而唯一的跟随路径 `LaunchedEffect(currentIndex)` **只在换行时**才跑 ⇒
超时之后没有换行（暂停 / 间奏 / 长句）就永久停在用户放手的位置。

## 4. 播放 / 暂停 / seek 都不重置计时（探针回答）

| 试验 | 观察 |
|---|---|
| 暂停 → 滑走 → 按播放 | +2.0s 仍 0.4170；+5.6s **换行**才回到 0.3599 |
| 暂停 → 滑走 → 点歌词行 seek | seek 生效（0:45→0:40），此后 **24 秒 7 次采样全部 0.4041** |
| 对照：从位移状态按播放 | +1.9s 仍 0.4041；+5.4s **换行** → 精确 0.3599 |

⇒ 唯一的回正触发是**换行**。
